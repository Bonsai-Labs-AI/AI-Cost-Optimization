# Tool matrix

The per-tool "how" for each technique, kept in one place so pages don't repeat it. Techniques are
rows, tools are columns, each cell is the exact knob (flag, command, file, or setting) — or `—` if it
doesn't apply, or `(confirm)` if not yet verified. Pages link to their row instead of restating every
tool. This table is also the artifact we hand a team in the "set it up in your repo" service.

> Started 2026-08-10. Grows as pages are written. First-class harnesses get columns; others (Windsurf,
> Gemini CLI, Goose, Amp) are noted inline where relevant.
